# KunRejam

KunRejam — Android uchun offline kunlik reja va odatlar ilovasi.

## Asosiy imkoniyatlar

- Kunlik vazifalarni qo‘shish, tahrirlash, bajarilgan deb belgilash va o‘chirish
- Ish, o‘qish, sog‘liq, sport, ibodat va shaxsiy kategoriyalar
- Bir martalik, har kunlik, ish kunlari va haftalik takrorlanish
- Native Android bildirishnomalari, ovoz va vibratsiya sozlamalari
- Pomodoro fokus taymeri
- Haftalik statistika, bajarilish foizi va streak
- Ma’lumotlarni qurilmada AsyncStorage orqali offline saqlash
- Yorug‘ va qorong‘i mavzu

Gemini maslahatlari hozircha o‘chirilgan. Keyingi versiyada API kalitini kodga joylamasdan xavfsiz server ulanishi orqali qo‘shish mumkin.

## Ishga tushirish

```bash
pnpm install
pnpm start
```

Android preview uchun Expo Go bilan QR kodni skanerlang. Native notification permission’ini ilova ichidagi **Sozlamalar** bo‘limidan yoqing.

## Texnologiyalar

Expo SDK 57, Expo Router, React Native, TypeScript, AsyncStorage, Expo Notifications va Expo Haptics.
